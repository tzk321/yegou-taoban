# 野狗逃班

手机浏览器上跑的横版跳跃小游戏，三代版本归档。

| 目录 | 版本 | 说明 |
|---|---|---|
| `野狗逃班-6.0/` | v6.0 | 14 技能之前的稳定版，构建脚本 + manifest + 交接文档齐全 |
| `野狗逃班-7.0/` | v7.0 | 「技能觉醒」版：14 个技能实战、120 秒四幕主线、12 图守夜者、本地成就 |
| `野狗逃班-SVG短片/` | v5.x | 早期 SVG 短片/分镜实验，逐字节可重建的构建流水 |

## 怎么玩

双击各目录下的 `night-off.html`，用**支持 JavaScript 的浏览器**打开即可离线玩，不需要安装、不需要联网、不需要同目录的 SVG。

- 触屏：左摇杆移动（上推跳、回中再上推二段跳、下拉急落），右下冲刺 / 大招 / 反击
- 键盘：`A` `D` 移动，`空格` 或 `↑` 跳，`S` / `↓` 急落，`Shift` 冲，`E` 大招，`F` 反击，`P` 暂停
- 存档、钱包、皮肤价格全在浏览器 localStorage，换浏览器等于新号

## 说明

- 每个版本都留了 `README-vX.txt` / `STATUS-vX.md`：那一轮改了什么、验收怎么过的，以文档为准
- 特效槽位固定（33 槽 / 99 后代），低端机不掉帧；暂停和切后台会冻结计时
- v6 之后没有覆盖旧入口，回退直接开老版本的 html
